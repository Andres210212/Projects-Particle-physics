# GRIPS tests

Notebooks de pruebas para análisis de datos abiertos de ATLAS usando
[`atlasopenmagic`](https://pypi.org/project/atlasopenmagic/).

## Contenido

- `test1.ipynb` — instalación del entorno con `atlasopenmagic` y notas sobre el bosón Z.

## Uso

```bash
python -m venv gripsenv
source gripsenv/bin/activate
pip install atlasopenmagic jupyterlab
jupyter lab
```

Luego abre `test1.ipynb` y selecciona el kernel del entorno.
